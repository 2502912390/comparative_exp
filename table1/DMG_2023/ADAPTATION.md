## Mechanism correspondence

- GNNDAE has one GCN encoder and decoder per provided relation. GCN uses dropout before bias-free Xavier linear projection, normalized adjacency multiplication, then native ReLU; common/private linear mappings retain PyTorch default initialization and widths. Decoder preserves Linearlayer depth and BatchNorm, final ReLU and linear reconstruction.
- One-time feature-column dropout is retained and its exact resulting per-view Boolean dropped-column masks are saved; inference reloads canonical features and applies these masks. Public canonical features themselves are unmodified and independently hashed.
- Provided positive relation supports are kept separately. The upstream loader adds sc*I to its raw adjacency. For canonical inputs, whose loader already supplied self-loops, this adapter explicitly removes those loops, takes positive off-diagonal support, and sets the diagonal to exactly sc=3 to avoid counting loader loops twice. This is an input adaptation, not byte-identical upstream preprocessing. It then uses `(degree+2.2204e-16)^(-1/2) A (degree+2.2204e-16)^(-1/2)`. All nodes/relations and direction remain. This method-specific operator is separately hashed; it is not a CCoE model graph. Sparse COO matrix multiplication matches asymmetric dense graphs and gradients.
- Cyclic topology neighbor sampling follows author row-major nonzero order: cache j=1..300, each column `offset + j % degree`. CSR offsets generate the same cache entry on demand, avoiding 300 copies on MAG. The author samples sample_neighbor+1 cache entries yet divides their sum by sample_neighbor; this precise behavior is retained. Sequential accumulation avoids retaining all feature gathers and has the same differentiable sum.
- Matching loss is summed MSE between concatenated common vectors and V copies of S divided by N. Reconstruction is summed feature and sampled-neighbor MSE divided by N. Independence is the absolute normalized centered scalar-product of nonlinear measurement networks; gradient reversal and the negative beta term remain. Native sample_num edge downsampling, cosine ranking (top20%, bottom10%), exp-temperature contrastive ratio and coefficients remain.
- Adam has one measurement group per relation with lr_max and weight_decay, plus GNNDAE lr_min with zero weight decay. S is alternately updated at every outer iteration by centered-common sum SVD, polar U T^T times sqrt(N), then inner_epochs full objective updates. The original range(2) in update_S would silently drop the third relation; it is generalized to all existing relations.
- Native loss stopping stays: strict loss improvement resets count, only strict deterioration after outer iteration100 increments it; stop at patience20. No validation labels enter unsupervised objective or this stopping rule. No clipping or extra stabilizing losses are added. Nonfinite original objective fails visibly.

## Checkpoint and evaluation adaptations

Author `use_pretrain=True` attempts loading saved_model/best_dataset_Node.pkl, but no code in the source saves it. This reproduction trains from scratch and uses its native-stopped backbone; it never reads an external author or CCoE checkpoint. This explicit repair avoids substituting unknown pretrained weights.

Representation is the final S plus arithmetic mean private embeddings. The final full-node S, GNNDAE, measurement networks, backbone optimizer, exact dropped-column masks and RNG are saved. Persisting S also prevents an SVD sign ambiguity during replay. One native Xavier initialized LogReg head is trained only on canonical train labels for author test_epo/test_lr. Validation accuracy strictly chooses best head checkpoint (earliest tie); no additional ten-probe averaging, validation hyperparameter selection, per-epoch test or F1-selected state. Native evaluator had no head early stopping, so its fixed probe budget is retained. All inference-chain components are checkpointed and fresh-process replay recomputes private embeddings and head scores, with no fitting or new SVD. Final all-node scores and masks support independent test ACC recount. The unsupervised backbone is fixed during the head checkpoint selection.
