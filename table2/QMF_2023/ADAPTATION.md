# QMF: static feature and multi-view adaptation

QMF variant is preselected from complete native RGBD NYUD2 code: Adam1e-4/wd1e-5, batch256, accumulation3, max500, patience20, ReduceLROnPlateau factor0.3/patience10, lambda0.1. These are fixed for all datasets. Appendix B.2 agrees on lr/lambda; text CLI max_epochs0 is not used as a training budget. No validation/test-based variant choice.

Per-view precomputed vectors replace BERT/ResNet raw-input backbones. Native hidden=[] means independent Linear(d_v,C) classifiers; no arbitrary new shared encoder, fake tokens/pixels or forced common hidden size. Native quality c_v=0.1*logsumexp(logits_v), fused_logits=sum_v(c_v*logits_v), no softmax normalization or probability averaging. RGBD keeps quality gradients (text implementation detaches; difference disclosed). Sum of CEs over V heads plus fused CE plus0.1*sum_v ranking losses retained without dividing by V.

Each training view has a separate History indexed solely by fixed train IDs; cumulative per-sample CE is min-max normalized over train samples. Native rolled pairs, direction sign, margin and MarginRankingLoss retained. Native RGBD ranks against previous history then adds current CE; text update-before-rank difference disclosed. Zero-spread initial/tied history is defined as target0/margin0, avoiding the released 0/0 bug. No epsilon/clipping or change when the native denominator is nonzero. All histories, weights, optimizer and scheduler states persisted. Validation/test inference receives no labels/history; replay loads saved history for identity but never updates it. No warm-start or multi-probe fitting.

The native accumulation factor3 is retained, including final incomplete groups using their actual microbatch count, rather than discarding training gradients at epoch boundaries. This explicit small-dataset correctness adaptation preserves every training sample. Default raw backbone dropout0.1 is inactive with native empty classifier hidden list; no artificial dropout added to static classifier.
